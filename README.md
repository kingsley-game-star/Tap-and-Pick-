# Tap & Pick — Party Challenges PWA

This folder is ready to deploy as a Progressive Web App.

## Publish it
Upload the entire folder to a static HTTPS host such as GitHub Pages, Netlify, Vercel, Cloudflare Pages, or your own HTTPS website.

The public URL becomes the app's install link.

## Android
Open the public URL in Chrome, then choose:
Menu → Add to Home screen / Install app.

## iPhone / iPad
Open the public URL in Safari, then:
Share → Add to Home Screen → Add.

## Important
The game is currently a PWA, not a native APK/IPA. It can be installed to the home screen and works offline after the first successful load.

To publish a native Android app on Google Play or a native iOS app on the App Store, the PWA can later be wrapped/build-packaged and submitted through the respective developer accounts.
